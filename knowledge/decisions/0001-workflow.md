# ADR 0001 — Knowledge-first discovery and Git flow

Status: accepted
Source: user's direct request, 2026-09-15
Updated: 2026-09-15

ทุกไอเดียต้องถามเจาะให้ครบก่อน plan และ implementation
ตรวจ rules → index → knowledge ก่อน research; knowledge แยกประเภทและหัวข้อ โดย index ชี้ไฟล์จริง
ใช้ Git flow และแยก branch ตามงาน
Implementation convention: main/develop + codex/{feature,fix,chore,release,hotfix}/topic
เอกสารแนบเป็น reference; engine, gameplay และ roadmap ในเอกสารยังเป็นข้อเสนอ
