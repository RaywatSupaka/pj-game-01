# Run modifiers — Augments, Events and Pair Synergies

Status: accepted prototype scope
Source: [roster discovery](../../discovery/0003-roster-synergy.md), [direction decision](../decisions/0002-roster-synergy-direction.md)
Updated: 2026-09-15

Each Run creates a different strategic question through three layers:

- **Augment:** choose one of three options; the effect lasts for the Run.
- **Event:** a visible temporary rule affects the Run or a defined 1–3 round window.
- **Pair Synergy:** a Race + Race interaction that can become stronger when an Augment or Event supports it.

Prototype scope: 6 Augments, 6 Events, three Augment choices per Run, three positive Race Pair Synergies and one conditional Rivalry pair.
All choices are seeded and show their effects before selection. Every Race remains viable alone.
Examples include an Orc–Human Alliance, Dwarven Industry, Bountiful Harvest and Festival Market.
Augments and Events are data-driven, localized and shown in the battle summary; exact values remain playtest tuning.
